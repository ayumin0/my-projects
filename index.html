Ciclos de faturamento

Cada ciclo guarda suas próprias datas, leitura inicial e histórico.

Para apagar um ciclo, use o botão vermelho Excluir ciclo no cartão. A exclusão também remove as leituras vinculadas e pede confirmação.

Tarifas e orçamento

Informe os valores que constam na sua conta. Não some novamente tributos que já estejam embutidos no preço por kWh.

Importante: a estimativa só será tão precisa quanto os valores cadastrados. Se o preço por kWh já inclui tributos e bandeiras aplicáveis, registre esses componentes uma única vez.

Dados e backup

Os dados ficam no armazenamento local deste navegador. Faça backup regularmente.

Privacidade: o backup é especialmente importante se você limpar os dados do navegador, trocar de aparelho ou abrir o site em outro navegador. Os dados locais não são sincronizados automaticamente entre dispositivos.
